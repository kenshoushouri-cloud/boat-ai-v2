# Value Candidate Shadow Review Checklist

Before any later rollout proposal, confirm:

- current production method is unchanged;
- analysis uses only pre-result information;
- low-odds segments are evaluated by value, not payout size alone;
- high-odds segments are evaluated by value, not jackpot contribution;
- results include candidate frequency, ROI, monthly profit/loss and losing streak;
- validation is out-of-sample;
- storage growth remains negligible;
- no persistent production research table is required.
